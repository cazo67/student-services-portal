# Student Services Portal

## Project Description

A TypeScript project that demonstrates student records, API responses, type safety, and runtime validation.

## Requirements

- Node.js
- npm
- Git
- A code editor such as Visual Studio Code

## Installation Instructions

Clone the repository and install its dependencies:

```bash
git clone https://github.com/cazo67/student-services-portal.git
cd student-services-portal
npm install
npm install
```
## How to Run the Project

Open a terminal inside the project folder and install the required packages:

```bash
npm install
```

Compile the TypeScript code:

```bash
npx tsc
```

Run the compiled project:

```bash
node src/index.js
```
